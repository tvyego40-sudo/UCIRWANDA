# UCIRWANDA
Ibanga uRwanda ribitse nyuma yirushanwa ry'Amagare hagiye kuza irushanwa ryitwa FOMULA1 Iri irushanwa rirakomeye ariko ntirirusha irushanwa ry'Amagare, inyungu irimo nuko igihugu cyacu nk'URwanda gikomeje gutumbagira .. ndetse no guhesha isura nziza igihugu, no kuzana ba mucyera rugendendo , tukinjiza amadovize menshi mu gihugu cyacu.
